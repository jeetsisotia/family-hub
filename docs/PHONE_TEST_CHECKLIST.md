# Phone checklist (one list)

Only what changed since 2.1.116 or was never tested on a real phone.

**Before you start:** do not turn Play Protect off.

1. **Install (Note 8):** download the newest `FamilyHub-2.1.x.apk` from GitHub Releases in Chrome and open it.
   - Expected: no "App blocked to protect your device" screen; Android's normal install prompt. If still blocked,
     tell me the exact text (screenshot) — do not bypass it.
   - Installs over the old app without uninstalling; you are still signed in; your data is there.
2. **Bank SMS:** Messages app → select 2–3 bank SMS → Share → Family Hub → transactions appear → tick → Add.
   Then Finance → Import bank alerts → Paste SMS with another message.
3. **Safety SMS:** Family safety → send a test message to yourself (SEND_SMS still works).
4. **Rules (after you approve and publish them):** a View-only member cannot add in Finance; None hides Health.
5. **Memories:** add 2 photos to a memory, react, comment; check on a second phone.
6. **Offline:** airplane mode → change a shopping item → "Offline · 1 change will sync" → back online → gone.
7. **Conflict:** two phones edit the same entry; the second to save is asked first.
8. **Backup:** Data & backup → Back up → Restore → "Verified on the server".
9. **Update:** Settings → App updates shows your version and "up to date".
10. **Note 8 extras:** a call between two phones; a reminder notification arrives on time (set battery to Unrestricted).
